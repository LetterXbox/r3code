A thread for every task

Each piece of work gets its own thread, grouped by project. Fork a thread to try another approach, and settle it when the work is done.

Pull requests in the app

Follow checks, comments and review activity for GitHub and GitLab pull requests next to the thread that produced them.

A real Mac app

Written in Rust, with GPUI and NativeShell as the front end. Signed with a Developer ID and shipped as a single download. It follows the design of T3 Code.
